# 🎬 Mihad Boom Shorts Website

Premium YouTube Shorts, Voice Over, Thumbnail, SEO Services website.

## 📁 Files in this Package

- `index.html` — Home Page (Packages, Testimonials, FAQ)
- `demo.html` — Demo Videos Gallery
- `order.html` — Order & Payment Form
- `style.css` — All styling with glowing effects & animations
- `script.js` — All animations, counters, countdown, etc.

## 🚀 How to Deploy on GitHub Pages

1. Upload all 5 files to your GitHub repository
2. Go to **Settings** → **Pages**
3. Source: `Deploy from a branch`
4. Branch: `main` → `/(root)`
5. Save
6. Wait 2-3 minutes
7. Your website will be live at: `https://your-username.github.io/repo-name/`

Open `index.html` and edit the `.package-card` sections.

Open `order.html` and edit the `selectPayment` calls.
